# Programação · Reset Marketing

Site estático da programação do Reset Marketing (16 e 17 de outubro, Florianópolis).

## Deploy na Vercel

- **Pelo painel:** suba esta pasta para um repositório no GitHub e importe em vercel.com/new. Não precisa configurar nada: o `vercel.json` já aponta para a pasta `public`.
- **Pela CLI:** `npx vercel --prod` dentro desta pasta.

Para editar horários ou palestrantes, altere `public/index.html`.
